# Musical Theatre Entry

Public introduction site for the independently developed Musical Theatre Entry app by RushLabs. English and Korean pages, local font, no scripts or analytics. The app is in preparation: the site intentionally has no download link.

Static site: `dist/`. Preview: `python3 -m http.server 8896 --directory dist`. Rebuild the two language pages with `python3 make_site.py`. Publish the `dist` contents from the `docs` folder through GitHub Pages branch deployment; no Actions workflow is included.

The notebook illustration is explanatory artwork, not an app screenshot. Descriptions are bounded to the existing app source: six local saved notebooks, added plan versions and version-bound records. The site does not claim repertoire approval, practical grading or official affiliation.
